# Dr.Lably Lab Bridge

Lab Bridge connects your lab analyzers to Dr.Lably. It runs on the Windows PC that is connected to your analyzers and sends their results to Dr.Lably automatically.

## Download
Get the latest version from [Releases](https://github.com/Dr-Lably/lab-bridge-releases/releases/latest):

| Your Windows | Download |
|---|---|
| 64-bit | `lab-bridge-vX.Y.Z-windows-amd64.zip` |
| 32-bit | `lab-bridge-vX.Y.Z-windows-386.zip` |

## Install
1. Unzip the file into one folder, for example `C:\DrLablyBridge`.
2. Follow `README.txt` in that folder.

Supported systems: Windows 7, 8.1, 10 and 11.

## Updates
Once installed, Lab Bridge updates itself. Each update is signed by Dr.Lably and checked before it installs.
